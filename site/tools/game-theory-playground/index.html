Game Theory Playground

Twenty interactive experiments in cooperation, negotiation, information, voting, and incentives. Make a choice, inspect the results, and change the rules.

Prototype Updated Sep 27, 2026
Live All Tools

Start with The Trust Machine, or explore the Game Theory Playground to choose an experiment.

Each experiment begins with a prediction, gives you a consequential choice, and shows the incentives behind the result. Change a setting to restart. Use “Share these settings” to copy a scenario link; links do not include play history.

Details

Built With
JavaScript, HTML, CSS, Jekyll
Topics
game-theory, learning, simulation, strategy, tools

Features

  • Twenty guided experiments with editable scenarios
  • Seeded simulations and settings-only scenario links
  • Visible assumptions, mathematics, and transfer questions
  • Keyboard-accessible controls and light and dark themes
